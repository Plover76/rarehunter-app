# 🛠 Git Commands Cheat Sheet (RareHunter)

Эта шпаргалка создана для удобной работы с Git в проекте RareHunter.  
В проекте используется **только ветка `dev`** для разработки.

---

## 🔹 Первичная настройка
```bash
# переключиться на dev и отправить её на GitHub
git branch -M dev
git push --set-upstream origin dev
```

---

## 🔹 Основной цикл работы
1. Проверить статус:
```bash
git status
```

2. Добавить изменения:
```bash
git add .
```

3. Создать коммит:
```bash
git commit -m "описание изменений"
```

4. Отправить изменения на GitHub:
```bash
git push
```

---

## 🔹 Получить новые изменения с GitHub
```bash
git pull
```

---

## 🔹 Отмена изменений
- Отменить изменения в файле:
```bash
git checkout -- путь/к/файлу
```

- Отменить последний коммит (если не пушил):
```bash
git reset --soft HEAD~1
```

---

## 🔹 Просмотр истории
```bash
git log --oneline --graph --decorate
```

---

⚡ Советы:
- Всегда проверяй `git status`, чтобы понимать текущее состояние.
- Используй осмысленные сообщения коммитов.
- Работай только в `dev`, а `main` создадим позже для релиза.
